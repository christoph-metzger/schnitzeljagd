# 🎂 Geburtstags-Schnitzeljagd

Dieses Projekt ist im Rahmen des Experimentierens mit **Claude Code** entstanden. Es dient ausschließlich dazu, die Möglichkeiten von Claude Code auszuprobieren und zu testen – von der Entwicklung einer Web-App bis hin zu Design-Anpassungen per natürlichsprachiger Anweisung.

Die App selbst ist eine passwortgeschützte, browserbasierte Schnitzeljagd für eine Geburtstagsfeier.
